Event Booking System (MERN + AI)
A full-stack event management platform featuring Google Gemini 1.5 Flash AI for automated content generation and a robust Node.js/React architecture.

🚀 Features
AI-Powered Categorization: Utilizes a hybrid AI approach with Gemini 1.5 Flash and GPT-3.5 to automatically categorize events.

Full-Stack Architecture: Built using the MERN stack (MongoDB, Express, React, and Node.js).

Secure Authentication: Features JWT-based login and registration.

Dynamic Previews: Includes AI-driven description generation for a better user experience.

🛠️ Tech Stack
Frontend: React.js

Backend: Node.js & Express.js

Database: MongoDB Atlas

AI Models: Google Gemini 1.5 Flash & OpenAI GPT-3.5

📦 Installation & Setup
Clone the Repo: git clone [https://github.com/Maka180/event-booking-system.git](https://github.com/Maka180/event-booking-system.git)

Backend Setup:

Navigate to cd backend

Run npm install

Create a .env file with your Mongo URI and API Keys.

Frontend Setup:

Navigate to cd frontend

Run npm install

Run the App:

Start backend: npm run dev

Start frontend: npm start
